Prepared 2026-09-14 for the current app catalog. The goal is to replace provisional
Vietnamese translations with the **actual wording shown in the game**.

English names below identify the existing records; they are not suggested
Vietnamese translations. Capture with the game set to Vietnamese. Counts describe
the app's current coverage, not necessarily everything available in the game today.

## How to capture

- Keep original resolution and Vietnamese accents readable. Send the original
  screenshots rather than a compressed collage.
- Keep the screen heading and enough context to identify the hero, fish or item.
  If a popup hides that context, take its parent screen immediately before it.
- On scrolling lists, overlap at least one row between screenshots so nothing is
  missed. Open a detail popup whenever a name is truncated.
- A label only needs one clear capture per distinct meaning/context. Repeated
  divinities, cores and stat labels do not need another shot for every hero or fish.
- If identity is unclear, capture the same screen in English and Vietnamese.
  Paired captures are especially useful for unfamiliar fish and ambiguous stats;
  they are not needed for every recognizable portrait.
- Capture labels and titles first. Full ability descriptions are optional for this
  pass; scroll farther when a core name, tier heading or other label is below the fold.
- Use readable locked previews where available. No need to unlock, upgrade or spend
  resources just to obtain a label; note anything unavailable.

## Outside this capture pass

- App-created controls such as Share, Import build, Important / Should have /
  OK to have, admin screens and user-written lineup/build names.
- New portrait crops, skins, investment-dependent numeric growth and unrelated
  game modes not represented in the app.
- Full description transcription, unless you also want to provide that for a
  later translation pass.

The captures will verify display translations while the existing entity IDs,
URLs and translation keys continue to identify the same game records.
